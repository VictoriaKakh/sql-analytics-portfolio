# **Цель:** рассчитать долю пользователей с одним заказом и с несколькими заказами среди платящих пользователей по дням.
Входные таблицы: user_actions (user_id, time, action, order_id)
Логика расчёта:
1.	Определяем платящих пользователей: те, у кого есть хотя бы один заказ без отмены (action != 'cancel_order').
2.	Считаем количество заказов в день для каждого пользователя и оставляем только те, где количество таких заказов у пользователя 1 с помощью HAVING count(distinct order_id)=1, т.е. count_with_1_purchase.
3.	Отдельно считаем общее число платящих пользователей в день, total_count.
4.	Находим долю тех, кто совершает одну покупку среди общего числа платящих пользователей в этот день, single_order_users_share. Находим вычитанием оставшуюся долю тех, кто совершил больше 1 покупки, several_orders_users_share.
Примечание: платящими считаются те пользователи, которые в данный день оформили (и не отменили) хотя бы один заказ. Исключаем заказы со статусом cancel. 
Выходные поля: date,  single_order_users_share, several_orders_users_share
